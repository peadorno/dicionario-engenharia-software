        Sobre o projeto

        Conhecimento técnico conectado, direto ao ponto.

        Este dicionário reúne conceitos de Engenharia de Software, inteligência artificial, tecnologia e governança de metadados. O objetivo é apoiar estudos e decisões do trabalho cotidiano, mostrando não apenas o significado de cada termo, mas também as relações entre eles.

        Como foi construído

        É uma aplicação web estática feita com HTML semântico, CSS responsivo e módulos JavaScript nativos. Os termos e as relações ficam separados em arquivos JSON, o que facilita revisão, versionamento e crescimento da base sem depender de framework, servidor ou banco de dados.

        Busca local e inteligente

        A pesquisa combina correspondência por nome, aliases e conteúdo, tolerância a variações de escrita e expansão de intenções relacionadas. Todo o processamento acontece no navegador; as consultas não são enviadas a serviços externos.

        Qualidade e publicação

        A base é validada por testes automatizados em Node.js, incluindo integridade dos dados, relações, busca e acessibilidade estrutural. O código é versionado com Git e publicado pelo GitHub Pages.
